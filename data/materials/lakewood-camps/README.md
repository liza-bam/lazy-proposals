## What is collected

The [complete asset manifest](photos/manifest.json) indexes 112 image paths, representing 84 distinct Git blobs, plus the Illustrator logo file. It records exact filenames, byte sizes, Git object hashes, retrievable source links and identical-blob relationships. The source tree was not truncated.

The files already exist in the public project repository. This pass indexes and links those collections; it does not claim that image bytes were newly copied into HQ or that an original-file ZIP was made. Source repositories retain the actual bytes and history.

Image counts include site photographs, selected derivatives, logos, design studies and generated imagery. Filenames that explicitly say ChatGPT Image are classified as generated artwork. That is not an exhaustive provenance check. Other images may also be generated, edited or stock. No unknown image is certified as original property photography.
